# 🎤 Классификация "Человек vs Робот" в аудиозвонках

Проект по детекции синтезированной речи в телефонных звонках. 
Сравнение различных моделей машинного обучения для определения, 
звонит реальный человек или робот с синтезированным голосом.

## 🎯 Описание проекта

Проект решает задачу бинарной классификации аудио:
- **Human** (0) - реальный человек
- **Robot** (1) - синтезированная речь (TTS)

**Особенности:**
- Специализация на русском языке
- Сравнение 7+ моделей машинного обучения
- Интерфейс для ручной проверки аудио
- Воспроизводимые эксперименты
