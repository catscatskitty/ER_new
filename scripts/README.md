# 🚀 Скрипты запуска

Универсальные скрипты, работающие на **Windows**, **Linux** и **MacOS**.

## 📋 Доступные скрипты

| Скрипт | Описание |
|--------|----------|
| `run_full_pipeline.py` | Полный пайплайн (подготовка данных → обучение → оценка) |
| `train_only.py` | Только обучение моделей |
| `evaluate_only.py` | Только оценка и сравнение |
| `launch_manual_checker.py` | Запуск интерфейса ручной проверки |
| `clean_results.py` | Очистка результатов экспериментов |
| `run_notebooks.py` | Запуск Jupyter notebooks |
| `make_executable.py` | Установка прав (для Unix) |

## 🎯 Использование

### На Windows:
```batch
python scripts\run_full_pipeline.py
python scripts\train_only.py
python scripts\launch_manual_checker.py
